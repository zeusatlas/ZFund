# NALO USSD Gateway Integration Guide

This document specifies the integration contract, request/response formats, direct event-code routing, and operational behavior between ZFund and the **NALO Solutions USSD Gateway**.

---

## 1. Provider Contract Overview

ZFund integrates with NALO via HTTP POST callbacks dispatched to:
`POST /api/v1/ussd/nalo`

### 1.1 Inbound NALO Request Payload
```json
{
  "USERID": "NALOTest",
  "MSISDN": "233240000001",
  "USERDATA": "*920*969*1001#",
  "MSGTYPE": false,
  "NETWORK": "MTN",
  "SESSIONID": "16590115252429751"
}
```

| Field | Type | Description |
|---|---|---|
| `USERID` | String | NALO-issued account identifier. |
| `MSISDN` | String | Contributor's phone number in international format (`233...`). Stored as string to preserve country code and leading zeros. |
| `USERDATA` | String | Raw text typed by the subscriber. On initial dial, this contains the dial string (e.g. `*920*969*1001#`); on subsequent turns, it contains menu choices (e.g. `1`, `50`). |
| `MSGTYPE` | Boolean | `false` on initial session initiation dial; `true` on continuing session requests. |
| `NETWORK` | String | Mobile network operator (MTN, Vodafone/Telecel, AT). |
| `SESSIONID` | String | Unique telecom session identifier generated by NALO. |

---

### 1.2 Outbound ZFund Response Format
```json
{
  "USERID": "NALOTest",
  "MSISDN": "233240000001",
  "MSG": "Welcome to Holy Trinity Parish\n1. Offering\n2. Tithe\n3. Building Fund\n0. Exit",
  "MSGTYPE": true
}
```

| Field | Type | Specification |
|---|---|---|
| `USERID` | String | Must match the incoming `USERID`. |
| `MSISDN` | String | Subscriber's phone number. |
| `MSG` | String | Text prompt rendered on the mobile handset. **Hard limit of 120 characters**. |
| `MSGTYPE` | Boolean | `true` = **Continue Session** (keeps mobile prompt open expecting next user input). <br>`false` = **End Session** (displays final message and terminates connection). |

---

## 2. Event Code Routing: Direct Project Entry

ZFund supports two dialing modes:

1. **General Dial (`*920*969#`):**
   - Routes to the global ZFund root flow.
   - Allows public contributors to search for projects by name, browse categories, or enter a known event code.

2. **Direct Project Dial (`*920*969*<EVENT_CODE>#`):**
   - Example: Dialing `*920*969*1001#` bypasses the general root menu and opens the project's published welcome menu immediately.
   - `NaloAdapter.parseRequest()` parses the suffix after the second `*` and extracts `1001`.
   - `UssdRoutingService` performs an indexed lookup on `projects.eventCode = '1001'`.
   - Verifies project status is `PUBLISHED` and `acceptsContributions = true`.
   - Loads the published `UssdFlowVersion` and initializes the session.

---

## 3. Provider-Side Configuration & Pre-requisites

For direct event code dials (`*920*969*<CODE>#`) to reach the backend, the following provider-side setup is required on the NALO Gateway dashboard:

1. **Shared Shortcode Provisioning:**
   The shortcode `*920*969#` must be configured with a wildcard or sub-code routing rule on NALO's gateway so that any dial starting with `*920*969*` forwards the full dial string in `USERDATA` to ZFund's webhook URL.
2. **Webhook URL Endpoint:**
   `https://<YOUR_API_DOMAIN>/api/v1/ussd/nalo`
3. **HTTP Timeout:**
   Set gateway timeout to **5000 ms** (5 seconds). ZFund's dual-layer Redis cache ensures response times under 50 ms.
