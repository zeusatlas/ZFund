ZFund Backend API Specification

Complete frontend developer reference for integrating React, Next.js, and Mobile clients with the ZFund contribution engine, database-driven USSD engine, Paystack mobile money gateway, and mNotify SMS provider.

⚡ Base URL: http://localhost:2077/api/v1 🔒 Auth: Bearer JWT (Argon2id) 📱 USSD Gateway: *920*969# 💬 SMS: mNotify Quick API
📋 Frontend Guide: How to Set Request Headers

Every request made by your frontend (Vite/React, Next.js, or mobile apps) must include standard HTTP headers depending on the type of operation:

Header Name Value Format When Required Description
Authorization Bearer <access_token> Protected Routes Pass the 15-minute access token obtained from /auth/login or /auth/register.
Content-Type application/json POST, PUT, PATCH Required for all endpoints accepting JSON payloads.
Content-Type multipart/form-data Document Upload Required when posting file uploads to /documents/upload using FormData.
x-correlation-id uuid / string Optional Pass client-generated ID to trace requests in backend structured logs.
x-paystack-signature HMAC SHA512 string Paystack Webhooks Webhook validation signature generated by Paystack servers.
x-nalo-token string USSD Gateway Pre-shared token for NALO USSD aggregator webhooks.
Frontend Example: Axios Client with Auto-Refresh Interceptor (Port 2077) 
import axios from 'axios';

// 1. Create configured Axios instance
export const api = axios.create({
  baseURL: 'http://localhost:2077/api/v1',
  headers: {
    'Content-Type': 'application/json',
    'Accept': 'application/json',
  },
  withCredentials: true, // Enables sending and receiving HTTP-only refresh cookies
});

// 2. Request Interceptor: Attach Access Token
api.interceptors.request.use((config) => {
  const token = localStorage.getItem('zfund_access_token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

// 3. Response Interceptor: Auto-Refresh Expired Token on 401
api.interceptors.response.use(
  (response) => response,
  async (error) => {
    const originalRequest = error.config;
    if (error.response?.status === 401 && !originalRequest._retry) {
      originalRequest._retry = true;
      try {
        const refreshRes = await axios.post(
          'http://localhost:2077/api/v1/auth/refresh-token',
          {},
          { withCredentials: true }
        );
        const newAccessToken = refreshRes.data.data.accessToken;
        localStorage.setItem('zfund_access_token', newAccessToken);
        originalRequest.headers.Authorization = `Bearer ${newAccessToken}`;
        return api(originalRequest); // Retry original failed call
      } catch (refreshErr) {
        localStorage.removeItem('zfund_access_token');
        window.location.href = '/login';
      }
    }
    return Promise.reject(error);
  }
);
