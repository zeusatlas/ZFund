# RaiseFundz logo kit

## Brand colors

- Charcoal: `#2B2926`
- Warm cream: `#EDEAE5`

## Files

- `raisefundz-horizontal-outlined.svg` — recommended vector master; the **reference R/arrow icon replaces the initial R**, followed by outlined **Outfit ExtraBold** letters `aiseFundz`.
- `raisefundz-horizontal.svg` — editable SVG; icon followed by live text `aiseFundz` in **Outfit ExtraBold**. Install Google Fonts Outfit to edit/render it accurately.
- `raisefundz-horizontal.png` — large raster logo on warm cream.
- `raisefundz-icon.svg` — standalone transparent vector symbol.
- `raisefundz-icon-on-cream.svg` — square warm cream icon.
- `raisefundz-icon-reversed.svg` — reversed square mark.
- `raisefundz-icon-transparent-512.png` — transparent high-res icon.
- `raisefundz-icon-512.png` — cream icon for app/social use.
- `favicon.ico` — 16/32/48/64px multi-size browser icon.
- `favicon-16.png`, `favicon-32.png` — PNG favicons.
- `apple-touch-icon.png` — 180px Apple touch icon.
- `android-chrome-192.png`, `android-chrome-512.png` — PWA icons.

## Website usage

```html
<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="icon" type="image/svg+xml" href="/raisefundz-icon-on-cream.svg">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<img src="/raisefundz-horizontal-outlined.svg" alt="RaiseFundz" />
```

Version 5 uses **Google Fonts Outfit ExtraBold** for the wordmark and retains the single-color vector tracing of the R/arrow icon from the supplied reference image. The icon **is** the first R of `RaiseFundz`, rather than sitting next to another R. All favicon and app assets use precisely the same mark. The outlined SVG is the recommended production file.
